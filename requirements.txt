# Requirements for running this app as a ZeroGPU Space with
# MODEL_BACKEND=qwen_image, set as an env var in the Space's own settings
# (app.py defaults to qwen_image_edit_comfy). A ZeroGPU Space installs a
# top-level requirements.txt automatically; it does NOT go through the
# Dockerfiles under docker/, which are separate deployment paths (each
# installs its own dependencies directly).
#
# Both frontends' own dependencies are listed here — nicegui runs fine on
# an ordinary Hugging Face Space, just not on ZeroGPU specifically: ZeroGPU
# (spaces.GPU) is tied to the Gradio SDK Space type, so a Space actually
# using ZeroGPU needs FRONTEND=gradio set as an env var in the Space's own
# settings (app.py's own frontend selector otherwise defaults to nicegui —
# see frontends/__init__.py). A non-ZeroGPU Space can leave FRONTEND unset
# and get nicegui, same as running this locally.
#
# Not needed by, and not installed alongside, qwen_image_edit_comfy's
# ComfyUI stack when that backend is deployed via its Dockerfile instead
# — see models/__init__.py's docstring for why the two backends' imports
# are kept lazy/separate regardless of which requirements file was used to
# install them.
gradio
nicegui

# Qwen-Image-2.1 inference (diffusers pipeline and AOTI kernels), a
# separate package under the Qwen Research License rather than the GPL. It
# pulls in the pinned diffusers commit, transformers, accelerate,
# torchvision and `spaces`. `torch` itself is assumed to already be
# present (as it is on a ZeroGPU Space).
ai-image-edit-qwen @ git+https://github.com/pulb/ai_image_edit_qwen

# core/imaging.py's LAB color-space math (shared by both models' masking)
# imports numpy and Pillow directly, so each gets its own line here.
numpy
pillow
